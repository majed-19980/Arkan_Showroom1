نظام معرض أركان المعارض — Google Sheets مركزي مع مزامنة تلقائية عند تسجيل الدخول

- بعد تسجيل الدخول تتم مزامنة البيانات من Google Sheets المركزي المرتبط بالتطبيق وتظهر شاشة انتظار قصيرة حتى تكتمل المزامنة.
- لا يظهر للمستخدم زر مزامنة في شاشة الدخول.
- الإضافة والتعديل والحذف والحفظ تستخدم ملف Excel المركزي.
- تم تثبيت رابط Google Apps Script داخل التطبيق، ولا يطلب الرابط من المستخدم.
- لا ترسل كلمة مرور Microsoft أو رمز التحقق.

- تم تثبيت رابط Web App الخاص بـ Google Apps Script داخل النظام.
- عند كل تسجيل دخول تتم مزامنة البيانات تلقائيًا من Google Sheets، ثم تُحفظ التغييرات تلقائيًا في الخلفية.
- أزرار حفظ/تحديث/حذف المشرف تعمل على البيانات المركزية أيضًا.
